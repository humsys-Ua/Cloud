## 🛠️ Технічний опис системи / Technical Overview

Модуль **«КРИВБАС-ЕКО-КЛИН»** — це мехатронний уніфікований фланець (∅ 600 мм) для врізки в промислові димарі важкої металургії та цементних заводів. Система здійснює перехоплення чадного газу (CO) та сажі з їх подальшим плазмохімічним перетворенням на **еко-метанол або еко-гас**.

### 🔧 Специфікація компонентів та матеріалів
*   **Корпус фланця:** Немагнітна сталь **AISI 316L** (12 мм) з внутрішнім термобар'єром із карбідокремнієвої кераміки (**SiC**, 20 мм).
*   **Захист оптики (Без ReBCO/Водню):** Двоконтурна іонізаційна сітка з ніхрому **Х20Н80** (+5 кВ) + постійні неодимові магніти **NdFeB (N52H, 1.4 Тл)** з водяним охолодженням + аеродинамічний бар'єр «Повітряний ніж» (Air Knife, 4–5 бар).
*   **Оптична система ADAOS:** Два 15-сантиметри дзеркала з реакційно-зв'язаного карбіду кремнію (**RB-SiC**) бреггівського типу (**48 шарів HfO₂/SiO₂**, R = 99.999%).
*   **Підвіс:** 4 кільцеві п'єзоактуатори (**PZT**) з частотою відгуку контуру до 50 кГц для гасіння промислових вібрацій.
*   **Параметри лазера:** Ітербієвий волоконний лазер, λ = 1064 нм, потужність **5 кВт**, тривалість імпульсу **30 пс**, частота пакетів **250 кГц**. Внутрішньорезонаторна потужність фотонної решітки — **50 МВт**.
*   **Хімічний каскад:** Кордієритова стільникова матриця з біметалічним нанонапиленням **Нікель-Кобальт (Ni-Co)** та церієвим промотором.

## 💻 Обчислювальна архітектура безпеки (Bare-Metal Rust)

Для запобігання гонкам даних (Data Race) між надшвидким ядром стабілізації резонансу (**Fast Loop, 200 кГц**) та ядром промислової автоматики/телеметрії (**Slow Loop, 10 Гц**) архітектура безпеки використовує атомарні операції послідовної узгодженості (`Ordering::SeqCst`). Це гарантує миттєвий апаратний відгук на забивання повітряного ножа або термічну деградацію постійних магнітів.

Реалізація логіки промислових взаємоблокувань (Interlock) винесена в окремий низькорівневий модуль автоматики безпеки проекту **«ХМАРИ»** (див. файл програми).

### ⚙️ Алгоритмічна матриця Interlock:
*   **Каскад «ЦЕМЕНТ»:** У разі падіння диференціального тиску повітряного ножа нижче критичних **3.5 бар**, мікроконтролер за < 2 мкс виконує послідовність: апаратне відсікання лазера на рівні GPIO → перекриття ШІМ-клапана пари → шиберна екстракція касети іонізаційної сітки в захисну нішу від цементного абразиву.
*   **Каскад «МЕТАЛУРГІЯ»:** Запобігає необоротній точці Кюрі для NdFeB магнітів N52H. При перевищенні +65°C автоматично вводиться резервний контур охолодження чиллера. При переході критичної межі в +75°C система повністю гасить лазер та знеструмлює високовольтний ключ сітки (+5 кВ -> 0 В).

## 🚦 Протокол запуску системи (Pre-start Interlock)

1.  **КРОК 1:** Увімкнення водяного чиллера оправ дзеркал та магнітних сорочок (\(T_{max} < +60^\circ\text{C}\)).
2.  **КРОК 2:** Подача осушеного стисненого повітря на ламінарний «Повітряний ніж» (\(0^\circ\dots5^\circ\) вздовж поверхні дзеркала).
3.  **КРОК 3:** Запуск промислового газу в трубу та прогрів внутрішнього контуру фланця до +500°C.
4.  **КРОК 4:** Подача перегрітої пари тиском 3–4 бар через верхні кутові форсунки для формування вортексу.
5.  **КРОК 5:** Активація високовольтного блоку іонізаційної сітки (+5 кВ).
6.  **КРОК 6:** Запуск імпульсного лазера (5 кВт) та автоматичне розгортання фотонної решітки до 50 МВт.
